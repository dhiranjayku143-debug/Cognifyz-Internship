## Tasks Completed

### Level 1: Beginner
- **Task 1: HTML Structure and Basic Server Interaction**: HTML forms for user input, a Node.js and Express server, endpoints to handle form submissions, and server-side rendering with EJS.
- **Task 2: Inline Styles, Basic Interaction and Server-Side Validation**: more complex forms, inline JavaScript for client-side validation, server-side validation, and temporary server-side storage for validated data.

### Level 2: Intermediate
- **Task 3: Advanced CSS Styling and Responsive Design**: multi-section layout, CSS transitions and animations, and a responsive UI using a CSS framework.
- **Task 4: Complex Form Validation and Dynamic DOM Manipulation**: advanced validation rules (e.g. password strength), dynamic DOM updates with JavaScript, and client-side routing.

### Level 3: Advanced
- **Task 5: API Integration and Front-End Interaction**: RESTful API with CRUD operations and a front end that fetches and displays data from it.
- **Task 6: Database Integration and User Authentication**: database integration, user authentication, and authorization checks on API endpoints.

## How to Run

1. Clone the repository
   ```bash
   git clone https://github.com/dhiranjayku143-debug/Cognifyz-Internship.git
   ```
2. Open any task folder
   ```bash
   cd Cognifyz-Internship/task1-2-beginner
   ```
3. Install dependencies
   ```bash
   npm install
   ```
4. Start the server
   ```bash
   node app.js
   ```
5. Open `http://localhost:3000` in your browser.
